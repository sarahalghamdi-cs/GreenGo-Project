# Green Go 🌿

A responsive web application for eco-friendly travel bookings, developed as a university project for the Web Technologies course (14705).

## ✨ Features
* Responsive layout designed for various screen sizes.
* Interactive booking and comparison pages for eco-friendly destinations.
* Clean and intuitive user interface built with modern front-end standards.

## 🛠️ Technologies Used
* **HTML5** & **CSS3**
* **JavaScript**

## 👩‍💻 Author
Developed as part of academic coursework for showcasing web development and UI/UX implementation skills.
